# Krystal's Adventure

A retro pixel-art platformer. Krystal runs across a city at sunset with her volleyball, fighting off an invasion of robots.

## Play

- **In a browser:** open `index.html` in a browser, or use the GitHub Pages link for this repo.
- **On a Mac:** double-click `Krystal's Adventure.app`.

## Controls

| Key | Action |
| --- | --- |
| ← / → or A / D | Run |
| Space / W / ↑ | Jump (hold to jump higher) |
| X / J | Serve the volleyball |
| X while in the air | **SPIKE!** (double damage) |
| Jump on a robot | Stomp |
| ↓ + jump | Drop through a fire escape |
| P / M | Pause / mute |

## Features

- Robot walkers, chasing drones, and rooftop laser turrets
- The volleyball comes back to Krystal, and it can knock lasers out of the air
- Stars, heart pickups, lamppost checkpoints, and 3 lives
- A boss fight against the **MEGA-BOT 9000**
- Chiptune music and sound effects made with the Web Audio API
- One HTML file with no dependencies and no build step
